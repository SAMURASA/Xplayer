## 🎧 Что такое XPlayer?

**XPlayer** — desktop-плеер для Windows, созданный вокруг локальной музыкальной библиотеки, но с функциями, которые обычно приходится собирать из нескольких отдельных приложений.

В одном плеере доступны:

- локальная музыка и видео;
- YouTube-поиск и сохранение треков;
- Discord Rich Presence;
- совместное прослушивание через **Party / Listen Together**;
- WebRTC P2P-first соединения;
- аудиореактивные визуалы;
- bass-reactive glow;
- Slowed / Nightcore / Reverb;
- профили и Profile Studio;
- Radio / HypeFM;
- отдельный **Potato Mode** для слабых ПК.

XPlayer ориентирован на обычное ежедневное прослушивание, но при этом позволяет превратить плеер в визуальную и социальную часть рабочего стола.

## ✨ Почему XPlayer?

### Всё в одном месте

Не нужно держать отдельный плеер для локальных файлов, отдельное окно YouTube и отдельную программу для Discord.

### Музыка + друзья

**Party** позволяет собрать комнату для совместного прослушивания, синхронизировать воспроизведение и работать с общей очередью.

### Визуалы без обязательной нагрузки

Визуалы можно настроить под свой ПК, а **Potato Mode** позволяет максимально снизить нагрузку, отключая самые тяжёлые визуальные и reactive-компоненты.

### Плеер, который можно настроить под себя

Profile Studio, рамки, стили карточки, эффекты, цвета, достижения и другие элементы превращают XPlayer в персональный интерфейс, а не просто список треков.

## ▶ YouTube

XPlayer умеет работать с YouTube непосредственно из интерфейса плеера.

Поддерживается:

- поиск прямо в XPlayer;
- кнопка **«Загрузить ещё»**;
- вставка прямой ссылки;
- получение реального названия и метаданных видео;
- сохранение трека локально;
- сохранение оригинального YouTube thumbnail;
- использование сохранённой обложки для локального трека и Discord Rich Presence;
- автозагрузка видеоклипов для отображения на фоне или вместо обычной обложки.

Для загрузки используется **yt-dlp**.

> Используй только контент, к которому у тебя есть право доступа и использования. Ограничения YouTube, регион, возраст и авторизация могут влиять на доступность некоторых видео.

## 👥 Party / Listen Together

Party — режим совместного прослушивания с друзьями.

### Что умеет Party

- до **6 активных мест**;
- общая очередь;
- синхронизация play / pause / seek;
- WebRTC **P2P-first**;
- TURN только как fallback;
- Metered Realtime для signalling;
- передача и предзагрузка локальных файлов;
- синхронизация эффектов воспроизведения;
- Discord join / invite-контекст.

### Как подключить Party

1. Создай проект в **Metered Realtime**.
2. Создай publishable key `pk_live_...`.
3. В XPlayer открой **Settings → Advanced network settings**.
4. Вставь ключ и сохрани настройки.
5. После этого можно создавать или подключать Party.

В XPlayer не нужен секретный server-side ключ Metered.

## 🎨 Визуалы

XPlayer включает визуальную систему, ориентированную на реакцию на музыку:

- audio-reactive визуалы;
- bass-focused glow вокруг обложки;
- настройка расположения и режима;
- performance-профили;
- качество визуализации;
- visual cache;
- настраиваемый цвет таймлайна.

### 🥔 Potato Mode

**Potato Mode** — отдельный режим низкой нагрузки.

Он предназначен для слабых ПК и игровых систем, которым нельзя отдавать большую часть CPU/GPU на визуализацию.

Режим отключает или ограничивает самые тяжёлые визуальные, reactive и preloading-компоненты, сохраняя основные функции плеера.

## 👤 Profile Studio

Profile Studio объединяет кастомизацию и достижения.

Доступны:

- стили карточки **Glass / Solid / Neon**;
- рамки профиля;
- цвет карточки и accent;
- эффекты аватара;
- эффекты баннера;
- статистика;
- реакции;
- уровни достижений;
- косметические награды.

Заблокированные косметические варианты нельзя применить до получения нужного достижения.

---

## 📻 Radio / HypeFM

Radio — отдельный сценарий воспроизведения, отделённый от обычных online-функций.

Во время радио обычные online-контролы и lyrics/text overlay не должны перекрывать или ломать радио-интерфейс.

## 🖱 Drag & Drop

Можно просто перетащить в XPlayer:

- отдельный музыкальный файл;
- несколько файлов;
- целую папку.

Не нужно добавлять каждый трек вручную.

## 📻 Какие форматы поддерживаются?

XPlayer работает с распространёнными локальными аудио- и видеоформатами, включая:

`MP3` · `M4A` · `AAC` · `OGG` · `Opus` · `WAV` · `FLAC` · `WebM` · `MP4`

Поддержка конкретного файла зависит от возможностей используемого playback stack.

## 🔐 Приватность и внешние сервисы

XPlayer в первую очередь работает с локальной медиатекой, настройками и профилем на вашем компьютере.

Внешние интеграции:

- **YouTube / yt-dlp** — онлайн-медиа и метаданные;
- **Metered Realtime** — signalling для Party;
- **WebRTC** — peer-to-peer соединения;
- **Discord Desktop** — Rich Presence.

Не публикуй API-ключи, cookies или другие секреты в Issues, README или репозитории.
